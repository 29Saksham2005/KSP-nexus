# KSP NEXUS

AI-Powered Crime Intelligence Operating System

---

## Overview

KSP NEXUS is an intelligence platform designed for Karnataka State Police to assist investigators using explainable artificial intelligence, relationship analysis, geospatial intelligence, timeline reconstruction, and operational dashboards.

The project follows:

- Modular Development
- API-First Development
- Layered (Clean) Architecture
- Repository Pattern
- Service Pattern
