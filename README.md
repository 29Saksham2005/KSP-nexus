# 📖 Overview

Crime investigations generate thousands of records every day. While every FIR tells an individual story, the real intelligence often lies in the connections between them.

Today, investigators spend valuable time searching through fragmented reports, spreadsheets, and isolated databases to uncover relationships between suspects, victims, locations, and recurring criminal behavior.

**KSP NEXUS** transforms disconnected crime records into actionable intelligence through an integrated Crime Intelligence Platform.

Instead of simply visualizing crime statistics, the platform helps investigators understand patterns, identify criminal networks, monitor emerging hotspots, and make faster, evidence-backed decisions.

---

# 🎯 Problem Statement

The Karnataka State Police currently faces challenges including:

- Fragmented crime records across independent systems
- Manual Excel-based reporting
- Lack of AI-driven crime intelligence
- Limited statewide analytical capabilities
- Reactive policing instead of proactive decision making

KSP NEXUS addresses these challenges by providing a unified intelligence platform for data visualization, crime analytics, and investigative support.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/KSP-nexus.git
```

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```
